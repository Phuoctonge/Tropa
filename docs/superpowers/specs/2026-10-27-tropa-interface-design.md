# Tropa preliminary interface

Approved in chat on 2026-10-27: a minimal main screen inspired by the simplicity of WARP and Amnezia. Theme is not restricted to dark. This document records that approved direction rather than reopening approval.

The main screen has the Tropa name, one large connection switch, a status, and two selection rows: game and server. A settings button opens another screen. Game, server and settings screens replace the content of the same window and have a Back button. X hides to tray; tray Exit performs controlled shutdown.

The game screen selects one local `.exe` for the first product slice. Persist the selected path beside the portable executable using backend-owned configuration. Selecting a file does not execute it or install routing rules. The server screen offers Automatic and an honest empty state until validated WARP candidates exist; there are no invented locations or latency figures. Settings offer system, light and dark themes, plus a separate route to existing technical tools.

Connection is unavailable until a verified WARP session coordinator exists. Running mihomo alone must not be labeled Connected. Explain the missing WARP profile beside the switch; do not simulate a successful connection. This deliverable is the preliminary interface, not completion of the tunnel/game-routing slice.

Use a warm neutral light surface, restrained orange accent, large whitespace, clear Russian copy and keyboard-accessible native controls. Respect reduced motion. Scale down to a compact window without horizontal scrolling. Keep the existing backend lifecycle and service restrictions.
