# Разработка без запуска TUN — 28 октября 2026

Работа выполняется по [плану дальнейших вех](../superpowers/plans/2026-10-28-tropa-next-milestones.md). По указанию пользователя запуск Tropa/UAC и испытания от администратора отложены; разрешены unit-тесты, статический анализ и сборка. Новые скачанные сторонние программы/скрипты не запускались.

## Диагностика

Добавлен безопасный Rust/TypeScript контракт `WarpFailure { stage, reason, retryable, transport }`. Этапы: registration/scanner/validation/runtime/routing/cleanup. Причины присваиваются в местах ошибок регистрации, сканера, запуска/проверки ядра и маршрутизации; wrapper сохраняет типизированную причину из anyhow chain. Текст ответа API, строки stderr, реквизиты и путь приватного runtime не входят в контракт.

Исправлено смешение пустой таблицы WarpScout и отсутствующего/некорректного отчёта. Исходный regression test был запущен до исправления и упал: обе ошибки имели одинаковый текст `WarpScout report contains no usable rows`. После исправления тест прошёл.

Отказ запуска/ранний выход transport core больше не должен попадать в обычный список недоступных кандидатов: тип Runtime сохраняется вместо преобразования в TransportUnavailable. Неуспешная остановка имеет приоритет над исходной сетевой ошибкой. Потеря процесса активного ядра отражается как Runtime/ProcessExited.

Проверка окончательного trace получила максимум 3 попытки с паузами 1/2 секунды и общим пределом 30 секунд. Автоповторы разрешены для timeout и конкретных временных connect I/O ошибок. HTTP-ошибки/407, неверный trace и отсутствие `warp=on|plus` не повторяются; redirects и скрытые retries HTTP-клиента отключены. Ответ ограничен 16 KiB. Регрессия временного timeout воспроизведена до изменения; после изменения локальный HTTP-стенд подтвердил восстановление, отдельный тест подтвердил отсутствие повторов 407/warp=off.

Итоговая проверка пакета: 401 Rust library test и 4 unit-теста routing fixture прошли; 50 frontend tests, TypeScript `--noEmit`, ESLint изменённого TypeScript и production Vite build прошли. После последних уточнений validator/Job Object библиотека повторно проверена: 401 passed, 0 failed. Эти результаты не являются свидетельством запуска desktop EXE или работы TUN.

## UDP / IPv6

Подготовлены standalone fixture, собственный echo responder и ручной сценарий трёх фаз. См. [точные границы и порядок](split-tunneling-udp-ipv6.md). Четыре loopback unit-теста fixture прошли; PowerShell-сценарий проверен синтаксически, его сетевые фазы не запускались. Реальная маршрутизация UDP/IPv6 остаётся NotTested.

## Оставшаяся работа

Вехи 1 и 2 не помечены завершёнными. В диагностике ещё нужен пригодный для экспорта набор версий/фактических хэшей, длительностей и стадий, отдельная обработка отказа UAC/часов и нативный отказ с проверкой очистки. Удаление временных файлов и долгоживущих ресурсов требует дальнейшего проверки восстановления при ошибках доступа; одна типизированная причина не доказывает успешной очистки.

Нативные проверки TUN, браузеров, античитов и чистой Windows отложены. Это не препятствует разработке независимых ограничений выбора, бюджетов WG/AWG и MASQUE identity; они остаются следующими невыполненными вехами. Массовая чистка проектной папки откладывается до рабочего проверенного комплекта, как просил пользователь: текущие исходники, данные и следы проверки не удалять произвольно.
