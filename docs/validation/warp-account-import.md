# Импорт регистрации WARP: фактическая проверка

> Исторический отчёт. После уточнения пользователя импорт убран из интерфейса/IPC. Актуальный сценарий и результаты — [автоматическая регистрация и сброс](automatic-warp.md). Локальное хранилище и его файловые регрессии переиспользованы.

Дата: 27 октября 2026 года. Проверяется локальный импорт по [плану](../superpowers/plans/2026-10-27-warp-account-import.md) и [проекту](../superpowers/specs/2026-10-27-warp-registration-design.md).

## Реализовано

В настройках Tropa появился импорт собственной основной WireGuard-регистрации WarpScout. Backend проверяет ID/токен, base64-ключи длиной 32 байта, ненулевые ключи и семейства IP-адресов. Неизвестные поля и вложенные регистрации MASQUE/outer не переносятся. Чтение ограничено 256 КиБ; размер нормализованного файла проверяется до записи.

Копия сохраняется атомарно в `app_home_dir()/secrets/warp-account.json`, в Windows portable это `data/secrets/warp-account.json` рядом с исполняемым файлом. Формат — JSON версии 1, без обязательного шифрования. Исходный файл не изменяется. Повреждённая запись и неизвестная версия дают ошибку чтения; заменить или удалить такую запись можно явно из интерфейса.

Команды сериализованы через config-write lock и возвращают только `missing` либо `imported` с `hasIpv6`. Аргумент импорта — путь к файлу. Ошибки фиксированные, tracing использует `skip_all`, секретная модель не имеет `Debug` и не возвращается в webview. `.gitignore` исключает runtime data, secrets и экспорты WarpScout.

Перед заменой и удалением есть подтверждение. Отмена выбора файла не вызывает импорт. Повторные операции блокируются до завершения. Успешная мутация обновляет статус; ошибка сохраняет прежнюю регистрацию. Переключатель подключения остаётся недоступным.

## Выполненные проверки

- `cargo test --locked -p clash-verge --lib --features clippy,portable`: **364 passed**, включая две новые проверки на синтетических данных. Проверены разбор, безопасный DTO, ошибочные поля, повторное чтение, сохранение прежних байтов, предельный размер, повреждённый файл, неизвестная версия, восстановительная замена и идемпотентное удаление. На Windows проверена неудачная замена файла, открытого без разрешения удаления; прежние байты сохранены.
- `pnpm@12.10.0 test`: **45 passed, 11 files**. TypeScript и ESLint прошли без ошибок.
- Headless Chrome: импорт, блокировка действий во время операции, отмена подтверждения и выбора файла, ошибка замены с сохранением статуса, удаление, восстановление после ошибки чтения, оба пути «Назад», недоступное подключение. Повторно проверены светлая/тёмная/системная темы и ширина 320 px без горизонтального переполнения. Использован отдельный `tropa-preview.html` с синтетическими состояниями и callback-операциями, без native bootstrap. Это не проверка реального Tauri-диалога.
- Независимое read-only ревью обнаружило увеличение JSON после нормализации у предела 256 КиБ. Сначала тест воспроизвёл ошибку, затем добавлена проверка размера до замены. Полный Rust-набор после исправления прошёл.
- Проверены существующие экспортёры: `core/backup.rs::create_backup` включает явный список профилей/конфигураций, без `secrets`; sysinfo-диагностика копирует системные сведения, без содержимого data. При добавлении runtime-конфига с ключами потребуется отдельная проверка экспорта.

## Ограничения и следующий шаг

Нативный запуск приложения, диалог выбора файла, сохранение после полного перезапуска и отказ доступа через Windows ACL пока не проверены. Файловые регрессии выполнены на Windows; блокировка файла и препятствие вместо каталога не заменяют отдельную проверку ACL.

До native smoke требуется отдельный этап изоляции updater/идентификаторов Tropa и проверки сетевых действий upstream при старте. Приложение для проверки импорта не запускалось, устройства Cloudflare не регистрировались, ядро/TUN и маршруты не менялись. Автоматическая регистрация, endpoint, координатор подключения и игровой маршрут остаются следующими этапами. Готового portable ZIP для распространения пока нет.
