# Выбор серверов Tropa: первый этап, 27 октября 2026

Реализованы каталог полных профилей и выбор automatic/manual, адаптер stock WarpScout для WG/AWG, проверка HTTPS WARP и серии UDP DNS запросов через pinned mihomo, повторное использование кэша и экран сохранённого выбора. Обычное подключение не требует выбора игры.

Это первый этап [плана](../superpowers/plans/2026-10-27-server-selection.md). Постоянное подключение через главный переключатель, обновление списка из GUI, TUN/UAC-координатор и автоматическая MASQUE EC-регистрация ещё не реализованы. Нативный GUI не запускался; его upstream updater/startup-эффекты ещё нужно изолировать.

## Фактический сетевой прогон

Zapret оставался включённым по указанию пользователя, официальный Cloudflare WARP — Disconnected. Использованы существующая собственная регистрация Tropa, оригинальный WarpScout 0.16.1 с закреплённым SHA256 и mihomo 1.19.33. Новая регистрация не создавалась, существующая не менялась. Диагностическое ядро слушало только loopback; TUN, системный DNS и системный proxy не включались.

| Сценарий | Время целиком | Сканер запускался | Результат |
|---|---:|---|---|
| Первый автоматический поиск | 18,21 с | Да | AWG standard, HTTPS WARP + 5/5 UDP DNS |
| Повторная проверка кэша | 2,74 с | Нет | Тот же профиль, HTTPS WARP + 5/5 UDP DNS |
| Обновление: два новых проверенных варианта | 37,98 с | Да | AWG standard и AWG QUIC, оба прошли HTTPS и 5/5 UDP DNS |
| Повторная проверка ручного выбора | 2,79 с | Нет | Сохранённый AWG QUIC, HTTPS WARP + 5/5 UDP DNS |

Лучший новый вариант по последней проверке имел медиану UDP DNS 8 мс. Для ручной проверки был выбран другой профиль с последующей медианой 19 мс; приложение сохранило его ID и endpoint, не заменив автоматически лучшим. Выбор для этого developer-теста был записан в каталог скриптом; нативный вызов команды GUI отдельно не проверялся. Страна выхода наблюдалась как RU, что не обещает её фиксацию или возможность выбрать произвольную страну.

Время измеряет обнаружение/проверку и завершение диагностического ядра, а не запуск постоянного TUN. UDP DNS RTT — не ping игры. Это один короткий последовательный прогон в текущей сети; долгие сессии и гарантии для других сетей из него не следуют.

До успешного прогона реальные запуски выявили ошибки схемы адаптера: stock `mihomo-json` возвращает корневой массив, а WG/AWG endpoint лежит в `peers[0]`. Парсер исправлен по исходникам закреплённого WarpScout; тест воспроизводит реальный формат с синтетическими реквизитами. После обоих неудачных запусков также подтверждена очистка и неизменность сети.

Материалы успешного прогона: `.artifacts/profile-selection-zapret-on/results.json`, `cleanup.json`; сценарий `.artifacts/test-profile-selection.py`. Полные параметры и реальные реквизиты остаются в исключённом из Git каталоге. Публичный DTO не передаёт в webview ID регистрации, токен, ключи или I1.

## Состояние после проверки

Адаптеры, default routes и системный proxy совпали с исходным снимком. Оставшихся дочерних scanner/core/probe процессов — 0; временных scanner-account, profile-export и runtime файлов с ключами — 0. Хэши сетевых бинарников и файла регистрации не изменились. Прямой trace — `warp=off`, официальный WARP по-прежнему отключён.

## Локальные проверки

`cargo test --locked -p clash-verge --lib --features clippy,portable,tropa-probe --offline --quiet`: 376 passed, 0 failed. Проверяются ручное закрепление, порядок по потерям перед RTT, сохранение всех AWG-параметров, отказ без повреждения файла, инвалидирование при другой регистрации и эксклюзивная OS-блокировка записи. В сетевую статистику допускаются минимум три успешных ответа из пяти.

TypeScript, ESLint, 45 существующих frontend-тестов и production web build прошли. Диагностический бинарник собран с `clippy,portable,tropa-probe`; обычный запуск Rust-тестов без Tauri test feature ранее завершился до выполнения тестов с Windows DLL `STATUS_ENTRYPOINT_NOT_FOUND`, поэтому использован проверенный ранее набор тестовых флагов проекта. Это не проверка готовой portable-поставки.

Независимое read-only ревью выявило и подтвердило исправление двух проблем: перезапись ручного выбора другим процессом и сохранение актуальности старых наблюдений после сброса регистрации. Запись каталога/изменение регистрации теперь сериализуются OS-блокировкой; проверка fingerprint регистрации скрывает старые результаты даже после прерванного сброса. После повторного ревью, включая формат stock-экспорта, материальных P1/P2 замечаний не осталось.
