Twemoji Mozilla emoji font

The Tropa frontend embeds a font inherited from Clash Verge Rev:
src/assets/fonts/Twemoji.Mozilla.ttf
SHA-256: 61db6397b8b32b72c585d538ef698a84cf78cf2558a14046b3fa0ec4cc362540

Source project: https://github.com/mozilla/twemoji-colr/tree/v0.7.0
Original release: https://github.com/mozilla/twemoji-colr/releases/tag/v0.7.0
Emoji artwork: Twemoji, Twitter and other contributors.
https://github.com/twitter/twemoji

Clash Verge Rev initially added the unmodified v0.7.0 release font in commit
50ba2e3ad4eabdf701e2c87cf511809d78605c28. It replaced it with the modified
font distributed here in commit b10c1d5006081d79c7517dce9fec83627f796d4a.
The conversion/rebuild process for that replacement has not been reproduced.
Tropa has not made further font modifications. No endorsement is implied.
